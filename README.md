# Clark

A personal AI butler for WhatsApp, iMessage, and the web — self-hosted on your own hardware.

Clark connects as a WhatsApp (and optionally iMessage) client, answers only for a pre-approved inner circle, and keeps the conversation in a local SQLite history. All replies are generated by your own Ollama model via a transport-neutral `gateway → assistant` pipeline.

```
WhatsApp ─┐
iMessage ─┼─► gateway → assistant (butler) → Ollama / tools → reply
Web chat ─┘
```

## Quick start

```sh
cp .env.example .env   # set OLLAMA_MODEL and OLLAMA_URL
go build -o clark . && ./clark init && ./clark run  # prints a QR code — scan in WhatsApp > Linked Devices
# or
docker compose up -d && docker compose logs -f
```

Verify: `./clark view` and, when the console is enabled, `https://clark.studio.lab`.

## Tools

VIPs may hold `web_search` or `view_history`; the Master additionally has `send_message`, `send_imessage`, `set_status`, `set_context`, `add_vip`, `delete_vip`, `set_access`, `get_state`, `view_all_history`, and `set_history_limit`. See `docs/web-console.md` and `docs/in-chat.md`.
