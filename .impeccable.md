# Clark Web Console — Design Context

## Design Context

### Users
- **The Master** (single primary user): opens the console from a phone or laptop at night, often from bed or a dark room. Jobs: check butler state, read chat, manage todos/kanban, review calendar, manage the protocols Clark writes, control cron schedules.
- **VIPs**: occasional visitors with read-mostly access (chat, history, own todos).

### Brand Personality
- Refined, quiet, butler-grade. The UI is the butler's uniform: composed, confident, expensive through restraint. Never loud, never cute, never "startup-y".
- 3 words: **refined · quiet · precise**.

### Aesthetic Direction
- Reference: **Linear-grade precision** — exact spacing, monochrome surfaces with one reserved accent, obsessive micro-detail, fast interactions.
- Theme: **dark, always** (usage context is dark rooms/night; dark is the design, not a toggle).
- Anti-references: generic admin dashboards, gradient/glow AI aesthetics, card-soup bento clutter, centered-everything marketing look.
- Typography: distinctive, not Inter/system defaults; monospace where data is monospace (logs, slugs, cron specs), refined sans for UI text.

### Design Principles
1. **Restraint is the luxury.** One accent, earned emphasis, no decoration that doesn't inform.
2. **Dark-native contrast.** Tuned for low-light rooms; no washed-out grays-on-dark.
3. **Density with hierarchy.** Data-dense surfaces (bento, logs) but unmistakable reading order.
4. **Every interactive surface feels intentional.** Focus states, hover states, empty states that teach.
5. **The butler speaks in UI too.** Copy is calm, precise, first-person-butler where appropriate.

### Accessibility Bar
Pragmatic AA-ish: contrast ratios, visible focus, keyboard paths, semantic controls. Full WCAG certification not required.
